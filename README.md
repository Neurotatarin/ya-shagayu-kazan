# Я шагаю по Казани

Ветка `demo/figma-restart`: девять экранов, собранных компонентами по Figma MCP.
Рабочая копия дизайна: `FxA6mFj3oiH58EvIa0dYeF`; вариант 6:822 и экран
ожидания 38:6309 из продолжения 37:6302. Главная принята Ленаром 30.10.2026;
он поручил собрать все остальные страницы. Старые варианты дизайна не используются.
Старая версия, её пять исходных файлов и `main` остаются без изменений:
https://neurotatarin.github.io/ya-shagayu-kazan/.

- React + TypeScript + Vite, Capacitor iOS. Android отложен.
- `app/src/data/homeRepository.ts` и `demoRepository.ts`: локальные данные
  макета, без API/Supabase. Дом Ушковой, Кул-Шариф и пять тем прогулок.
- Главная, карта, место, плеер, начало чата, диалог, ожидание, профиль, маршруты.
  Hash-навигация, поиск, листание тем, отмена запроса и небольшие окна действий.
- Избранное и позиция истории сохраняются локально через отдельный адаптер;
  это не аккаунт и не синхронизация между устройствами.
- `app/src/domain/` и `app/src/platform/`: независимые контракты данных,
  будущих нативных фонового аудио и офлайн-файлов; эти функции ещё не реализованы.
- `app/public/assets/home/` и `screens/`: неизменённые оригиналы Figma.
  `figmaAssets.ts` хранит исходные размеры, `figmaArt.ts` — порядок и геометрию
  векторных слоёв. SVG-контуры не переписываются. Фото сохранены по реальному формату.
- `branding/app-icon.png`: оригинальный PNG из 38:6926 с настроенным в Figma
  экспортом 1024×1024, без увеличения. Используется в браузере и IPA.
- Onest 400/500/600 и Tenor Sans 400 поставляются локально с лицензиями.
- Системные часы, вырез и индикатор жеста не рисуются в веб-интерфейсе;
  на устройстве используются настоящие системные панели и safe-area.
- На ПК композиция шириной 402 px по центру; телефоны используют ширину экрана.
- Анимации нет. Карта — оригинальный фон и схема из Figma с отдельными
  интерактивными метками, а не работающая GPS/пешеходная маршрутизация.
- Чат воспроизводит пример из макета и явно сообщает об отсутствии OpenAI.
  Ожидание можно отменить; ответы не выдаются за работу ИИ.
- У плеера работает выбор/сохранение позиции, переключение скорости и интерфейс
  паузы. Готового аудиофайла нет; воспроизведение и фон не проверены.
- API, SQLite, email-вход, синхронизация, награды, покупка, полноценный офлайн,
  системные виджеты и уведомления iOS остаются отдельными интеграциями.

Node 24, pnpm 11.25.0: `pnpm install --frozen-lockfile`, `pnpm dev`.
`pnpm build` проверяет TypeScript и собирает `dist/`.
`pnpm test:e2e` проверяет Chromium и WebKit с несколькими размерами экрана.
WebKit с параметрами iPhone XR не является симулятором или физическим iPhone.

CI `.github/workflows/demo-build.yml` проверяет веб и собирает на macOS 15 /
Xcode 26.3 неподписанный arm64 IPA для физического телефона. Подпись и установку
через Sideloadly выполняет Ленар на Windows; Apple ID в CI не используется.
Иконка установки получена из продолжения оригинального дизайна.

Публикация — только готовая статика в отдельном каталоге VPS, с резервной копией
и атомарным переключением `current`. Конфигурация nginx и другие проекты
не меняются. `preview-hold/` хранит обратимое перенаправление на старую версию.
Приблизительная предыдущая главная сохранена только в архивной ветке
`archive/manual-home-2026-10-29`; её UI в новой реализации не используется.

Известное противоречие дизайна: у карточки «Имперская Казань» в 11:9283 нет
иллюстрации; поза 01-museum расположена отдельно на доске компонентов. Карточка
воспроизведена по экрану маршрутов, без самостоятельного добавления персонажа.
В исходном экспорте иконки 38:6926 есть красный фрагмент справа внизу;
он сохранён как в Figma и требует уточнения у дизайнера.
