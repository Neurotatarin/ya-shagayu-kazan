# Я шагаю по Казани

Ветка `demo/figma-restart`: новая основа и только главная, собранная заново
по платному Figma MCP: файл Матвея, вариант 6:822, экран 6:835.
Старая версия, её пять исходных файлов и `main` остаются без изменений:
https://neurotatarin.github.io/ya-shagayu-kazan/.

- React + TypeScript + Vite, Capacitor iOS. Android отложен.
- `app/src/data/homeRepository.ts`: локальные данные макета, без API/Supabase.
- `app/src/domain/` и `app/src/platform/`: независимые контракты данных,
  будущих нативных фонового аудио и офлайн-файлов; эти функции ещё не реализованы.
- `app/public/assets/home/`: неизменённые оригиналы Figma; SVG используются
  в исходных размерах. Кремль сохранён как JPEG по фактическому формату файла.
- Onest 400/500/600 и Tenor Sans 400 поставляются локально с лицензиями.
- Системные часы, вырез и индикатор жеста не рисуются в веб-интерфейсе;
  на устройстве используются настоящие системные панели и safe-area.
- На ПК композиция шириной 402 px по центру; телефоны используют ширину экрана.
- Анимации нет. Незавершённые переходы показывают «Раздел в разработке».

Node 24, pnpm 11.25.0: `pnpm install --frozen-lockfile`, `pnpm dev`.
`pnpm build` проверяет TypeScript и собирает `dist/`.
`pnpm test:e2e` проверяет Chromium и WebKit с несколькими размерами экрана.
WebKit с параметрами iPhone XR не является симулятором или физическим iPhone.

CI `.github/workflows/demo-build.yml` проверяет веб и собирает на macOS 15 /
Xcode 26.3 неподписанный arm64 IPA для физического телефона. Подпись и установку
через Sideloadly выполняет Ленар на Windows; Apple ID в CI не используется.
Иконка установки пока сохранена от старого проекта; новый значок не придумывался.

Публикация — только готовая статика в отдельном каталоге VPS, с резервной копией
и атомарным переключением `current`. Конфигурация nginx и другие проекты
не меняются. `preview-hold/` хранит обратимое перенаправление на старую версию.
Приблизительная предыдущая главная сохранена только в архивной ветке
`archive/manual-home-2026-10-29`; её UI в новой реализации не используется.
