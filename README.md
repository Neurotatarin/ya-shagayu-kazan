# Я шагаю по Казани

React + TypeScript + Vite, Capacitor iPhone; основа `demo/figma-restart`.
Дизайн — `FxA6mFj3oiH58EvIa0dYeF`, вариант 6:822 и ожидание 38:6309.
Главная принята Ленаром. Оригинальные фото, персонаж, SVG и шрифты сохранены.
Старый `main` и опубликованная версия GitHub Pages не меняются.

Рабочие подключения:

- Python 3.10+ без дополнительных серверных пакетов; SQLite через API.
- MapLibre GL JS 6.16 + векторные данные OpenFreeMap/OpenMapTiles/OSM.
  Оригинальные маркеры и интерфейс Figma. GPS запрашивается пользователем;
  вне Казани реальные координаты не заменяются координатами города.
- Пешеходные линии FOSSGIS/OSRM foot: геометрия улиц, расстояние и время.
  Сервер ограничивает общий поток до одного запроса в 1,1 секунды и кэширует
  результат на сутки. Это публичный сервис без гарантии доступности; собственный
  региональный маршрутизатор остаётся вариантом для следующего масштаба.
- Зилант: Responses API, gpt-5.4-mini-2026-03-17, структурированный ответ.
  Рекомендованные ID проверяются по каталогу; путь рассчитывается отдельно.
  Ключ находится в защищённой конфигурации VPS, отсутствует в репозитории и IPA.
  Не более 4 запросов/минуту с IP, 20/сутки на гостя и 40/сутки с IP;
  резервирование стоимости ограничивает запросы приложения суммой $1/сутки.
  Это ограничение приложения, не всего аккаунта OpenAI. История — до 8 сообщений,
  удаление старше 30 дней; тексты и ключи не выводятся в журналы API.
- Гостевые избранное, ручные посещения «Я здесь» и позиции сохраняются в SQLite.
  Локальная очередь защищает последнее изменение при быстрой перезагрузке.
  Это ещё не email-аккаунт и не объединение устройств.
- Готовые оригинальные MP3 Ленара: 20 русских экскурсий; Кремль и башня Сююмбике
  дополнительно на английском и арабском — всего 24 записи. Длительности измерены
  по файлам. Язык выбирается строго: для отсутствующего перевода Play недоступен.
  Позиции хранятся отдельно для места и языка. Браузер использует Audio/Media Session,
  оболочка iPhone — AVPlayer/AVAudioSession; есть необязательный музыкальный фон.
  Фоновое воспроизведение на физическом iPhone ещё требует проверки Ленаром.

Контент:

`server/catalog.json` — 20 географических объектов, пять планов прогулок.
Координаты заново сверены с OSM; ошибочные архивные координаты Кремля не импортированы.
У каждой точки есть ссылка на первичный объект. Данные © OpenStreetMap contributors,
ODbL; требуется атрибуция OSM/OpenMapTiles/OpenFreeMap на карте.
У всех 20 мест есть фотогалереи; текстовые расшифровки аудио не подключены.
Контент и состав прогулок требуют приёмки. Параметры карточек берутся
из рассчитанных пешеходных линий; время осмотра в них не входит. Ленар подтвердил
полную «Новую Казань» с фактическими 14,5 км вместо 4 км из макета.

Пока не подключены: email-коды и объединение данных,
правила наград, тестовая покупка, защищённая админка, полноценные офлайн-пакеты.
Кэш каталога/линий не является полноценным офлайном карты и экскурсии.
Массовая загрузка публичных OSM-тайлов не используется.

Разработка: Node 24, pnpm 11.25.0, Python 3.10+.
`python server/server.py`, отдельно `pnpm dev`; Vite проксирует /api на 8792.
`pnpm build`, `python -m unittest discover -s server -p test_server.py`,
`pnpm test:e2e`. UI-тесты подменяют OpenAI и карту детерминированными ответами;
живые проверки провайдеров выполняются отдельно. WebKit XR — эмуляция браузера,
не физический iPhone и не симулятор iOS.

VPS: отдельный каталог /opt/kazan-demo, пользователь systemd DynamicUser,
SQLite в /var/lib/kazan-demo, только loopback:8792, прокси существующего тестового
виртуального хоста. Скрипт deployment/publish-api.py сохраняет конфигурацию,
предыдущую версию и консистентную копию SQLite; nginx -t до применения и откат
при ошибке. Автоматическое внешнее резервное копирование ещё не настроено.
Статическая сборка передаётся готовой; сборка на маломощном VPS не запускается.
CI на macOS собирает unsigned arm64 IPA; подпись Sideloadly выполняет Ленар.

Аудиофайлы хранятся отдельно от Git и приложения. Каталог приходит через API;
добавление записей не требует новой сборки сайта или IPA. Пакет оригиналов
проверяется ffprobe и полным декодированием локально. Серверный импорт
`deployment/update-audio-library.py` проверяет SHA256, сохраняет приватную копию
SQLite и атомарно обновляет только аудиополя и устаревшие описания мест.
Откат восстанавливает изменённые поля, сохраняя новые гостевые данные.
